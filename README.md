# Cove Studio 🥥✨
The creative companion to [Cove Vault](https://idunnoletmeinbro.github.io/cove-vault/), made for Coconut Cove Creations. It's the place for brainstorming, mood boards, sketching, palettes and avatar concept sheets.

- **Idea Inbox**: fast capture with text, links, #tags, pasted, dropped or picked images. Star, status (spark → exploring → planned → made), search and filter. Android share-target support.
- **Mood Boards**: freeform canvas with image, note, text, swatch, link and owned-asset tiles. Drag, resize, rotate, pinch or scroll to zoom, set a cover, export as PNG.
- **Sketch Pad**: pen, brush and eraser, size control, brand palette and color picker, undo/redo, a reference image underlay with adjustable opacity, save to gallery, export as PNG.
- **Palette Lab**: edit, copy and save palettes, extract colors from an image, harmony ideas, avatar silhouette preview.
- **Concept Cards**: full character sheet linked to a palette, board and sketches, exported as a PNG card or printed.
- **Spark Generator**: species + theme + palette + accessory + twist, with per-slot lock and reroll, and save to Inbox.
- **Reference Gallery**: categories (hair, outfits, poses, textures, accessories…), tags, send to a board.
- **Cove Vault bridge**: import a Cove Vault export and drop owned assets onto boards.

Local-first (IndexedDB `cove-studio`). It works offline and can be installed as a PWA. Use More → Backup to move data between devices.

```
npm install && npm run dev      # develop
npm run build                   # output in dist/
```
